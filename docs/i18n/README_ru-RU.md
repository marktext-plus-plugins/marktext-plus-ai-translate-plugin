# ИИ-помощник для MarkText Plus

Основное приложение: [MarkText Plus](https://github.com/SugarFatFree/marktext-plus)

[English](../../README.md) | [简体中文](README_zh-CN.md) | [日本語](README_ja-JP.md) | [한국어](README_ko-KR.md) | [Deutsch](README_de-DE.md) | [Français](README_fr-FR.md) | [Italiano](README_it-IT.md) | Русский | [Español](README_es-ES.md) | [Português](README_pt-PT.md) | [العربية](README_ar-SA.md) | [Português (Brasil)](README_pt-BR.md)

Писать, вычитывать и переводить той моделью, которую вы настроили в MarkText Plus. Нужен MarkText Plus 1.6.1 или новее.

Этот репозиторий намеренно не проверен MarkText Plus. Прочитайте исходники, прежде чем ставить, — это четыре коротких файла.

**По-прежнему 0.x.** Протокол плагинов редактора устаканивается, но ещё не устоялся, и этот плагин следует за ним.

## Что он делает

Правый щелчок в редакторе.

| Пункт | Что делает |
|---|---|
| **ИИ-письмо** | Скажите, что нужно сделать, — или возьмите один из обычных ответов — и он перепишет выделенное. Без выделения перепишет документ; на пустом документе напишет по одному вашему заданию |
| **ИИ-вычитка** | Орфография, опечатки, грамматика и знаки препинания, и ничего больше: голос принадлежит автору. Отвечать не на что, потому что исправлять ошибки — это всё задание |
| **Перевести выделенное** | Появляется, только когда что-то выделено |
| **Перевести документ** | Появляется, только когда ничего не выделено |

В правой боковой панели есть ещё значок для письма — вход, когда ничего не выделено и ничего не открыто.

**Письмо и вычитка сначала показывают результат.** Он появляется в области рядом с текстом с кнопкой «Применить»; применение идёт через историю редактора, и одна отмена возвращает всё назад. То, что вернула модель, стоит прочесть прежде, чем оно окажется в том, что вы писали.

**У перевода нечего применять.** Заменить документ его переводом — не то, что кто-либо имеет в виду под словом «перевести»; он показан, чтобы его прочли и скопировали. Целый документ переводится порциями и появляется по мере готовности — начало можно читать, пока конец ещё в пути, а сбой стоит одной порции, а не файла. Рисуется так, как вы читаете: исходником рядом с исходником, свёрстанным рядом с предпросмотром.

## Как это устроено

Четыре файла: [`plugin.lua`](../../plugin.lua), модуль API из SDK [`lib/marktext-plus.lua`](../../lib/marktext-plus.lua), [`lib/prompts.lua`](../../lib/prompts.lua) с запросами и вашими правками к ним, и [`lib/blocks.lua`](../../lib/blocks.lua), который режет документ на абзацы и снова собирает их в запросы. `plugin.lua` подключает их через `require`. Ни сборки, ни зависимостей, одинаково на Windows, macOS и Linux. Работает в песочнице внутри редактора: ни файловой системы, ни сети, ни библиотеки `os` — `require` достаёт только до собственного каталога плагина.

**Запросы лежат здесь, в плагине**, и именно они сохраняют Markdown целым:

```
- Preserve every Markdown construct exactly: headings, lists, tables,
  links, images, footnotes, block quotes and front matter.
- Do not translate code inside fences or inline code, URLs, file paths,
  or HTML tag names.
- Keep the same block order and the same number of blocks.
```

Ключ API держит редактор, и запрос отправляет он же; плагин его никогда не видит и сам в сеть не выходит.

## О чём он просит

| Право | Зачем |
|---|---|
| `document.read` | текст, с которым работать |
| `document.write` | чтобы применить переписанное, и только когда вы нажали «Применить» |
| `ai.chat` | чтобы спросить настроенную вами модель |
| `storage.local` | чтобы помнить ваши запросы и язык перевода |
| `ui.contextMenu` | четыре пункта правого щелчка |
| `ui.sidebar` | значок письма |
| `ui.settings` | свою страницу настроек |
| `ui.notifications` | чтобы сказать, когда работать не с чем |

Он не просит `network.request`, а значит не может отправить ваш текст туда, куда его не отправил редактор. `document.write` редактор проверяет в момент нажатия «Применить», а не со слов плагина.

## Настройки

Шесть полей на собственной странице: системный и пользовательский запрос для каждой из трёх команд. Чем модель является и что ей дают — разные вещи, которые хочется менять по отдельности; а модель, раз за разом портящую перевод определённого рода документов, лечат тем, что пишут об этом в запросе, — и снаружи плагина этого не сделать.

| Подстановка | Чем заполняется |
|---|---|
| `{{text}}` | текстом, с которым идёт работа |
| `{{language}}` | выбранным языком перевода |
| `{{instruction}}` | тем, о чём вы попросили письмо |

Шаблон, забывший `{{text}}`, получает текст в конце: запрос, в котором не с чем работать, хуже неопрятного. Каждое поле показывает своё значение по умолчанию, чтобы было видно, что вы меняете; очистить его — вернуть умолчание.

Двойные фигурные скобки, а не `${...}`: та форма означает подстановку в Dart, в шаблонных строках JavaScript и в оболочке, а `$` вдобавок разделитель KaTeX, который этот редактор отрисовывает.

## Языки

Двенадцать, как у редактора: English, 简体中文, 日本語, 한국어, Deutsch, Français, Italiano, Русский, Español, Português, Português (Brasil) и العربية. Добавить ещё один — несколько строк в `locales` в [`manifest.json`](../../manifest.json); pull request приветствуются.

## Установка

Скачайте ZIP из релиза и выберите в MarkText Plus **Плагины → Установить из ZIP**, либо найдите его через **Обзор**: на этом репозитории стоит GitHub-топик `marktext-plus-plugin`.

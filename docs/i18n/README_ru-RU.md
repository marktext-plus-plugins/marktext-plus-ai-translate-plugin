# Плагин ИИ-перевода для MarkText Plus

Основное приложение: [MarkText Plus](https://github.com/SugarFatFree/marktext-plus)

[English](../../README.md) | [简体中文](README_zh-CN.md) | [日本語](README_ja-JP.md) | [한국어](README_ko-KR.md) | [Deutsch](README_de-DE.md) | [Français](README_fr-FR.md) | [Italiano](README_it-IT.md) | Русский | [Español](README_es-ES.md) | [Português](README_pt-PT.md) | [العربية](README_ar-SA.md) | [Português (Brasil)](README_pt-BR.md)

Переводит выделенный фрагмент или документ целиком через ту модель, которую вы настроили в MarkText Plus. Требуется MarkText Plus 1.6.1 или новее.

Этот репозиторий намеренно не проверен MarkText Plus. Прочитайте исходный код перед установкой — это два коротких файла.

## Что он делает

Щёлкните правой кнопкой в редакторе. Если текст выделен, предлагается **Перевести выделенное**; если ничего не выделено — **Перевести документ**. Каждый пункт появляется только тогда, когда он уместен, так что вам никогда не предложат тот, которого вы не имели в виду.

О языке перевода спрашивают один раз — привычные можно выбрать нажатием, а введённое вместо них берётся как есть — и ответ запоминается на следующий раз.

Перевод выделенного возвращается в небольшом окне с кнопкой копирования. Перевод документа открывается на панели рядом с вашим текстом, где его можно читать вместе с оригиналом. **В ваш документ ничего не записывается**: перевод, который вы ещё не прочли, — это не та правка, о которой вы просили.

## Как это устроено

Два файла: [`plugin.lua`](../../plugin.lua) и [`lib/marktext-plus.lua`](../../lib/marktext-plus.lua) — модуль API из SDK, который `plugin.lua` загружает через `require`, никакой сборки, никаких зависимостей, одинаково на Windows, macOS и Linux. Он выполняется внутри редактора в песочнице без файловой системы, без сети и без библиотеки `os`.

**Подсказка для модели живёт здесь, в плагине**, и именно она сохраняет Markdown целым:

```
- Preserve every Markdown construct exactly: headings, lists, tables,
  links, images, footnotes, block quotes and front matter.
- Do not translate code inside fences or inline code, URLs, file paths,
  or HTML tag names.
- Keep the same block order and the same number of blocks.
```

Ключ API хранит редактор, и запрос отправляет тоже он; плагин никогда его не видит и сам ничего в сеть не пишет. Модели передаётся ровно приведённый выше текст, к которому добавлен ваш документ.

## О чём он просит

| Разрешение | Зачем |
|---|---|
| `document.read` | прочитать текст для перевода |
| `ai.chat` | обратиться к настроенной модели |
| `storage.local` | запомнить язык перевода |
| `ui.contextMenu` | два пункта контекстного меню |
| `ui.settings` | собственную страницу настроек |
| `ui.notifications` | сообщить, что ничего не выделено |

Он не просит `document.write`, поэтому не может изменить ваш документ, даже если попытается, и не просит `network.request`, поэтому не может отправить ваш текст никуда, кроме того адреса, куда его отправил редактор.

## Настройки

Одно поле на собственной странице настроек: язык перевода по умолчанию. Плагин заполняет его за вас и обновляет каждый раз, когда вы выбираете другой.

## Языки

Пункты меню и вопросы поставляются на English, 简体中文, 日本語, Deutsch и Français. Добавить ещё один — это несколько строк в `locales` внутри [`manifest.json`](../../manifest.json); пул-реквесты приветствуются.

## Установка

Скачайте ZIP из релиза и воспользуйтесь пунктом **Плагины → Установить из ZIP** в MarkText Plus либо найдите плагин через **Обзор**: у этого репозитория есть тема GitHub `marktext-plus-plugin`.

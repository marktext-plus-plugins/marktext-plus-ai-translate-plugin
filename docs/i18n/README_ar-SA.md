# إضافة الترجمة بالذكاء الاصطناعي لـ MarkText Plus

التطبيق الرئيسي: [MarkText Plus](https://github.com/SugarFatFree/marktext-plus)

تترجم النص المحدَّد، أو المستند بأكمله، عبر النموذج الذي أعددته في MarkText Plus. تتطلَّب الإصدار 1.6.1 من MarkText Plus أو أحدث.

هذا المستودع غير موثَّق من MarkText Plus عن قصد. اقرأ الشيفرة قبل تثبيتها — إنها ملف واحد.

## ما الذي تفعله

انقر بالزر الأيمن داخل المحرِّر. إن كان هناك نص محدَّد، يُعرض عليك **ترجمة التحديد**؛ وإن لم يكن هناك تحديد، **ترجمة المستند**. ولا يظهر أيٌّ منهما إلا حين ينطبق، فلا يُعرض عليك أبدًا ما لم تقصده.

تُسأل مرة واحدة عن اللغة الهدف — اللغات المعتادة حاضرة للنقر، وما تكتبه بدلًا منها يُؤخذ كما هو — ثم تُحفظ إجابتك للمرة القادمة.

تعود ترجمة التحديد في نافذة صغيرة فيها زر نسخ. أما ترجمة المستند فتُفتح في لوحة بجانب نصك، حيث يمكنك قراءتها مقابل الأصل. **لا يُكتب شيء في مستندك**: ترجمة لم تقرأها بعد ليست تعديلًا طلبته.

## كيف تعمل

الإضافة كلها هي [`plugin.lua`](../../plugin.lua) — ملف واحد، بلا بناء، وبلا اعتماديات، وهي نفسها على Windows وmacOS وLinux. تعمل داخل المحرِّر في بيئة معزولة بلا نظام ملفات، وبلا شبكة، وبلا مكتبة `os`.

**التوجيه المُرسل إلى النموذج موجود هنا، داخل الإضافة**، وهو ما يحافظ فعليًا على سلامة Markdown:

```
- Preserve every Markdown construct exactly: headings, lists, tables,
  links, images, footnotes, block quotes and front matter.
- Do not translate code inside fences or inline code, URLs, file paths,
  or HTML tag names.
- Keep the same block order and the same number of blocks.
```

المحرِّر هو من يحتفظ بمفتاح الـ API وهو من يرسل الطلب؛ الإضافة لا تراه أبدًا ولا تكتب شيئًا على الشبكة بنفسها. ما يُعرض على النموذج هو بالضبط النص أعلاه متبوعًا بمستندك.

## ما الذي تطلبه من أذونات

| الإذن | السبب |
|---|---|
| `document.read` | قراءة النص المراد ترجمته |
| `ai.chat` | مخاطبة النموذج الذي أعددته |
| `storage.local` | تذكُّر لغتك الهدف |
| `ui.contextMenu` | مدخلَا قائمة الزر الأيمن |
| `ui.settings` | صفحة إعداداتها الخاصة |
| `ui.notifications` | إخبارك حين لا يكون هناك تحديد |

لا تطلب `document.write`، فلا تستطيع تغيير مستندك ولو حاولت، ولا تطلب `network.request`، فلا تستطيع إرسال نصك إلى أي مكان لم يرسله إليه المحرِّر.

## الإعدادات

حقل واحد في صفحة إعداداتها: اللغة الهدف الافتراضية، تملؤها نيابةً عنك وتحدِّثها كلما اخترت غيرها.

## اللغات

تأتي مداخل القوائم والأسئلة بالإنجليزية و简体中文 و日本語 وDeutsch وFrançais. إضافة لغة أخرى تحتاج بضعة أسطر في `locales` داخل [`manifest.json`](../../manifest.json) — وطلبات الدمج مرحَّب بها.

## التثبيت

نزِّل ملف ZIP من صفحة الإصدارات واستخدم **الإضافات ← التثبيت من ZIP** في MarkText Plus، أو اعثر عليها عبر **الاستكشاف**: هذا المستودع يحمل موضوع GitHub `marktext-plus-plugin`.
